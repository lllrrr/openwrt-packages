- 开发测试覆盖配置生成、转义、停用项、独立启停、差异 reload、自动认证、loopback API、看门狗、状态解析。
- RPC 操作、真实临时本机 frps 端口转发、页面新建与应用、APK 生命周期经过测试。

- 验证不是所有协议/所有硬件的兼容性保证；未实际断电测试。

## 已知限制

- 当前仅发布 APK，不支持直接用于 opkg。
- 自动状态 API 端口为 27400–27999，实际容量受占用端口和设备资源限制。
- 状态 RPC 顺序查询连接；很多连接或无响应 API 会增加刷新耗时。
- 无代理或 visitor-only 连接的卡片状态不能单凭 API 列表准确证明已登录；可结合日志确认。
- 附加 TOML 字段冲突时 `frpc verify` 会失败；目前应结合日志或 checkconfig 命令排查。
- 测试辅助脚本依赖开发机器临时路径及测试连接，未作为可直接执行的公众维护工具发布。
