# luci-app-wan-latency v1.5.0

- 新增按实际运营商标记采样、历史筛选和逐目标延迟/丢包对比。
- 兼容同卡槽手动换 SIM，过期或新连接之前的缓存不用于归档。
- 支持 MU300 原生双 SIM 数据卡切换和任务状态跟踪。
- 手动标记绑定当前 SIM 指纹，换卡不继承，两个监控插件共用。
- 保留旧二进制历史，旧数据归为未标记。
- 修复失败样本缺失和稀疏时间序列索引问题，确保分组丢包按原始采样计算。

发布文件：通用 IPK、自解压安装器、源代码 ZIP、SHA256SUMS。
详见 docs/carriers.md。OpenWrt 25.12 采用源码文件部署，IPK 供 opkg 系统使用。
