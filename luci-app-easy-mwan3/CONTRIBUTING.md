# Contributing to Easy MWAN3

感谢你考虑为 Easy MWAN3 Configurator 做贡献！

## 如何贡献

### 报告Bug
通过 GitHub Issues 提交bug报告，包括：
- Bug描述和复现步骤
- OpenWrt版本和路由器型号
- 相关日志和截图

### 提交代码
1. Fork仓库并创建分支
2. 进行修改并测试
3. 提交Pull Request

### 代码规范
- Lua代码使用2空格缩进
- Makefile使用Tab缩进
- 添加必要的注释

## 许可证
贡献的代码将按照MIT License许可。

详细指南请查看 GitHub 仓库。
