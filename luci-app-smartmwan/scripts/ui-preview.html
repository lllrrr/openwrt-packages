smartmwan 组件预览

本页加载的是仓库里的真实组件代码（smwcore / smwoverlay / smwfeedback / smwform / smwpopover）与真实样式，只把 LuCI 运行时换成最小替身。 用法：在仓库根目录执行 python3 -m http.server 8080，然后打开 http://localhost:8080/scripts/ui-preview.html。 切换系统的浅色/深色外观即可核对两套主题。

按钮

六种形态：主操作、次重要、描边、文字、危险、危险文字。状态层由 currentColor 叠加，不依赖主题。

弹层（Dialog / Drawer / Sheet / Confirm）

PC 居中、手机贴底；关闭按钮 / 遮罩 / ESC 各自可配；提交期间不可关闭；未保存改动会二次确认。

反馈（Toast）

四类语义、去重、上限 4 条、错误常驻、可带一个操作按钮、进行中→完成的状态迁移。

浮层（Popover / Tooltip）

挂 body，逃逸父级 overflow；边缘自动翻转；外部点击与 ESC 关闭。

表单控件

标签 / 说明 / 错误行三段式，aria 关联齐全；IP 与端口执行格式校验（后端仍然权威）。

可折叠分组（高级设置）

加载与进度

区域加载、骨架屏、不确定进度（没有真实数值时不画百分比）、按钮加载态。

页面级零件

区块卡片、统计卡、键值表、徽标、表格（含表头气泡说明）。
