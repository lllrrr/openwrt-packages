内核模块

两个内核都是独立模块，可分别安装/升级，升级互不影响，也不会中断正在运行的测速（下一次运行生效）。 节点兼容性：mihomo 支持 vless / vmess / trojan / ss / hysteria2 及 tcp / ws / grpc / h2 / http 传输，xhttp 目前仅 VLESS；xray 支持 vless / vmess / trojan / ss （SS 不支持 plugin）及 tcp / ws / grpc / xhttp 传输，不支持 hysteria2 （Xray 26 也已移除 h2/http 传输）。VMess/Trojan 的 xhttp 节点请选 Xray。

独立模式不改写 PassWall 节点 address，也不切换全局节点；节点、IP 列表、探测/下载参数 仍用本操作台的配置。节点类型与选中内核不兼容时自动回退 PassWall run_socks。
