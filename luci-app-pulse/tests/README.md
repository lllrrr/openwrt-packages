# 回归测试

在仓库目录运行：

```sh
sh tests/run.sh
```

需要 Linux、Node.js 18 或以上、Python 3、Git、Make、Bash 和常用 shell 工具。不需要 npm/pip 依赖、SDK、浏览器或 OpenWrt 设备。GitHub 的 Ubuntu runner 直接运行同一命令。

- 前端：多标签页选择、存储不可用、接口消失、WAN 优先级、macvlan/网桥/DSA 归属、IP 与 DNS、流量平滑边界及原始数据保护。
- 版本：无 Git 历史及浅克隆、版本覆盖、构建时写入前端、正式版及修订版标签校验。
- 翻译：自动发现语言目录，检查模板覆盖、空翻译和占位符，不依赖预先生成的 `.lmo`。
- 安装：用模拟发布资产检查包选择、摘要校验、下载及安装失败后的行为，命令和系统路径均隔离，不执行真实安装或联网。

`tests` 工作流在分支推送、PR 和手动触发时执行。APK 构建工作流复用它，测试通过后才开始准备 SDK。测试文件不复制进 SDK 包目录，也不安装到路由器。

LuCI 模块通过轻量依赖桩加载。DNS 内联逻辑和工作流版本检查使用源码片段运行；调整这些代码的结构或步骤名称时，需要同步更新测试适配器。

这组测试不覆盖浏览器布局、主题适配、真实 RPC 权限和后台采集服务，这些仍需单独验证。
