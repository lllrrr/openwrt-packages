# luci-app-pm(PowerManager)

Luci plugin that makes OpenWrt poweroff and reboot easy.

## 🚀 Features

- Let OpenWrt or based OpenWrt releases poweroff and reboot easy.
- Total file size about **5KB**!
- Support most platforms.

## ⬇️ Downloads

[GitHub Release](https://github.com/morouter/luci-app-pm/releases)

## ⚠️ Warning

- Some devices not support poweroff, maybe can't work.
