# 数据面（eBPF）

一个对象，两个程序，由后台（Go，cilium/ebpf）以 TCX 挂在主路由 LAN 口（br-lan）上：

| 程序 | 挂载点 | 作用 |
| --- | --- | --- |
| `sr_egress` | egress | 读取发往设备的明文 DNS 应答，记录 IP → 域名（`sr_dns`），始终放行 |
| `sr_ingress` | ingress | 新连接首包按“设备 → 分流顺序 → 规则组 → 出口”判断，设置 mark 并记入连接表（`sr_conn`），后续包沿用 |

转发由 `ip rule fwmark` + 每个出口一张路由表完成；拦截、“压回 v4”用路由表里的 `prohibit` 路由实现，不在 eBPF 里处理。

```sh
go generate ./internal/bpf   # 开发机（clang + libbpf-dev）：bpf2go 编译并生成 Go 绑定，产物嵌入后台程序；24.10（6.6）与 25.12（6.12）通用
```

## 表（固定在 /sys/fs/bpf/smartroute/，由后台填写，停止时删除）

| 表 | 类型 | 键 → 值 |
| --- | --- | --- |
| `sr_cfg` | 数组[1] | 分流条数、mark 掩码、连接空闲超时、域名记录最短保留时间。分流条数为 0 时新连接一律直连（已有连接仍沿用连接表），所以最后写 |
| `sr_policy` | 数组[32] | 分流：设备组位图、规则组位图、mark、标志（全部设备 / 全部目标 / 取反）。mark 为 0 表示直连 |
| `sr_hits` | 每 CPU 数组[32] | 每条分流的命中次数 |
| `sr_mac` | 哈希 | MAC → IPv4 设备组、IPv6 设备组、是否出口自身（永不分流）。IP 规则关联的 MAC 只填 IPv6 设备组 |
| `sr_dev4` / `sr_dev6` | 前缀树 | 源地址 / 网段 → 设备组位图 |
| `sr_skip4` / `sr_skip6` | 前缀树 | 内置保护网段（私有、组播、本地网段），命中即不分流；发往路由器本机的由 `bpf_fib_lookup` 判断 |
| `sr_rg4` / `sr_rg6` | 前缀树 | 目标网段 → 规则组位图。前缀树只返回最长前缀，**重叠网段的位图由用户态合并后写入** |
| `sr_dom` | 哈希 | 域名后缀哈希 → 规则组位图 |
| `sr_dns` | LRU 哈希 | IP → 域名（线格式，右对齐）、TTL、记录时间、标签起点位图 |
| `sr_conn` | LRU 哈希 | 五元组 → mark、最后活动时间。只记交给出口（mark ≠ 0）的 TCP/UDP 连接 |

**域名后缀哈希**：把后缀写成线格式（小写，含结尾 0），对各字节**逆序**做 FNV-1a 64。例如 `foreign.lab` →
`07 'foreign' 03 'lab' 00` 逆序逐字节计算。ingress 从域名末尾往前扫，每到一个标签起点查一次 `sr_dom`，
所以 `domain:foreign.lab` 同时命中 `www.foreign.lab`。用户态实现见 [`internal/rules`](../internal/rules/rules.go) 的 `DomainHash`。

## 连接保持规则

- TCP 只在 SYN（不带 ACK）上判断；不在连接表里的已有连接保持直连，所以开启插件或修改分流不会打断已有连接。
- UDP 每个不在表里的包都会判断（无法区分新旧），判为经出口后记入连接表。
- ICMP 等无端口协议逐包判断，不记连接。
- 连接表条目空闲超过 `idle_s` 失效。

已知限制（代码里以 `shortcut:` 标注）：IPv4 非首个分片、带扩展头的 IPv6 包按直连处理。

## 校验器踩坑记录

- 对循环变量取地址（作为 map 键）会让它落到栈上变成未知值，校验器报“infinite loop detected” → 复制到单独的键变量。
- 逐字节扫描域名的循环和外层分支组合后超过 100 万条指令 → DNS 记录时预先右对齐并记下标签起点，ingress 用 `bpf_loop`（内核 ≥ 5.17）逐字节回调，回调只校验一次。
- 回调里的上界判断被编译器优化掉 → `barrier_var` 后再用掩码限定下标。

## 验证结果（2026-11-21，PVE 测试环境）

24.10.6（内核 6.6）与 25.12.2（内核 6.12）结果相同，与手写 nft 规则的 POC 一致：

| 场景 | 结果 |
| --- | --- |
| client-a（MAC 规则，含 v6 临时地址）× 国内取反 | 国外 v4 / v6 经网关，国内直连 |
| client-b（IP 规则，v6 经关联 MAC）× `domain:foreign.lab` | 解析 foreign.lab 后，对应的 v4 / v6 地址经网关；其他地址直连 |
| 流量卸载开 / 关 × 长连接（40MB） | v4、v6 全程经网关 |
| 下载中途开启分流 | 旧连接保持直连、不中断 |
| 下载中途把设备移出设备组 | 旧连接保持经网关、不中断 |
| 关闭后残留 | 无（tc、固定的表、ip rule、nft） |
