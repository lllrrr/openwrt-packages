# 系统规则

1. **中西文排版**：中文与英文、数字之间必须添加一个半角空格（例如：`FRP 节点`，`端口 8080`），但在标点符号旁除外
2. **标点符号**：除非原文有，否则不要随意添加句号。使用全角标点（，。：），但涉及代码参数或命令时保持半角。
3. **简洁性**：UI 界面空间有限，译文应在准确的前提下尽可能简短

## 常用术语表 (Terminology)

请严格遵守以下术语对照，不要使用直译：

### 产品名词

- `PortWeaver` :: **端口工具箱**

### 核心动词与状态

- `Forward` (verb/noun) :: **转发** (绝对不要翻译为“前进”)
- `Listen` :: **监听**
- `Reuse Address` :: **地址复用** (Socket 术语，不要译为“重用地址”)
- `Running` (project status) :: **运行中** (不要译为“正在进行”)
- `Traffic In / Out` :: **入站流量 / 出站流量** (比“流入/流出”更专业)
- `Toggle` :: **切换** 或 **开关**
- `Traffic In` :: **入站流量**

### 名词与对象

- `Client` :: **客户端** (不要译为“客户”)
- `Port` :: **端口**
- `Token` :: **Token** 或 **令牌** (视语境，API 认证通常保留 Token 或译为令牌)
- `Secret` :: **密钥**
- `Domain` :: **域名**
- `Proxy` :: **代理**
- `Extended Parameters` :: **扩展参数** (不要译为“高级参数”)
- `Address Family` :: **IP 版本**
- `Authentication Token` :: **认证令牌**

### 量词与描述

- `Size` (referring to ranges) :: **数量** 或 **长度** (不要译为“尺寸”)
- `Active` :: **活动** 或 **生效**
- `any zone` :: **任意区域**

## 注意事项

- 保持技术术语的一致性，某些属于可以使用括号标注英文原文以便理解
- 对于引号内的内容，保持原文，如果是代码或参数，切勿翻译

## 常见错误修正指南

1. **语境识别**：
   - 原文 `"Forward"` 在此软件中指 **端口转发**，严禁翻译为“前进”
   - 原文 `"client(s)"` 指软件客户端，严禁翻译为“商业客户”

2. **拼接字符串处理**：
   - 错误示例：" port " -> "端口"
   - 正确示例：" port " -> " 端口 " (保留了原有空格)

3. **标点符号**：
   - 避免在 UI 文本中添加不必要的句号，除非原文有
   - 使用全角标点符号（，。：）时，注意代码参数或命令保持半角
