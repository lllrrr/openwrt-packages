# Changelog

## 1.1.1 - 2026-07-12

- 使用持久化可用性事件补齐设备重启前的 24 小时时间线，并由本次开机后的 RAM 采样覆盖详细状态与延迟
- 保留真实的无数据和中断区间，不将重启间隙误标为正常
- 时间线统一使用路由器生成时间，避免客户端时钟偏差造成色条错位
- 使用半开时间窗口并提高无数据状态优先级，避免整点零时长状态或同桶成功样本污染色条
- 不增加高频闪存写入，现有配置、首次监测时间和历史事件可直接沿用

## 1.1.0 - 2026-07-12

- 默认增加 AliDNS 与 DNSPod 两个国内 HTTPS 轻量探测
- 升级时幂等补齐新目标，同时保留用户现有配置和法定数
- 在 README 中明确 LuCI 入口位于“状态 → 互联网连接”

## 1.0.1 - 2026-07-12

- 修复历史时间线聚合输出分隔符，确保状态与延迟正确显示
- 增加真实采样格式的 `getHistory` 回归测试
- 修复 GitHub Actions Linux runner 的容器产物目录权限

## 1.0.0 - 2026-07-11

- 首个稳定版本
- 多目标 ICMP/HTTP 公网连接探测与法定数判断
- 失败/恢复防抖状态机
- 24 小时时间线、24 小时/7 天/30 天可用率与中断事件
- LuCI 状态页和完整 UCI 设置页
- OpenWrt 23.05.6、24.10.7 IPK 与 25.12.5 APK 构建
- 简体中文界面与响应式暗色主题
