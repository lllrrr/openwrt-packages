💻 命令行 (curl) 

# HTTP Proxy
export http_proxy=http://[Router IP]:7890
export https_proxy=http://[Router IP]:7890

# SOCKS5 Proxy
export ALL_PROXY=socks5://[Router IP]:7891

🐳 Docker 

# ~/.docker/config.json
{
  "proxies": {
    "default": {
      "httpProxy": "http://[Router IP]:7890",
      "httpsProxy": "http://[Router IP]:7890"
    }
  }
}
💡
提示： <%:Replace [Router IP] with your actual router IP address (usually 192.168.1.1 or similar). The mixed port (default 7893) supports both HTTP and SOCKS5 protocols.%>
