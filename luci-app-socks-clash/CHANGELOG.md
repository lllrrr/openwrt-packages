# Changelog

All notable changes to this project will be documented in this file.

## [1.2.0] - 2025-12-23

### 🎉 重大更新

**SocksClash v1.2.0** 是一个重大版本升级，复刻了 OpenClash 70-80% 的优秀功能，但专注于"仅代理"场景。

### ✨ 新增功能

#### 订阅管理增强
- **节点过滤器**
  - 关键词包含过滤（用 `|` 分隔多个关键词）
  - 关键词排除过滤
  - 节点类型过滤（SS/VMess/VLESS/Trojan/Hysteria/TUIC）
  - 移除重复节点
  - 节点数量限制
- **订阅信息解析**
  - 从 `Subscription-Userinfo` 头解析流量信息
  - 显示已用/总流量、到期时间
- **自动更新设置**
  - Cron 时间表达式配置
  - 支持多种时间间隔（每小时/每6小时/每天/每周）

#### 配置生成器重写
- **智能节点合并**
  - 从所有订阅文件自动提取和合并节点
  - 去重处理
- **自动生成代理组**
  - 🚀 PROXY - 主选组（手动选择所有节点）
  - ♻️ AUTO - 自动选组（URLTest，300秒测速间隔）
  - 🔄 FALLBACK - 故障转移
  - 🎯 DIRECT - 直连
  - 🛑 REJECT - 拒绝
- **配置文件验证**
  - 使用 Clash 内核验证配置正确性
  - 失败自动回滚

#### 内核管理增强
- **版本管理**
  - 自动检测最新版本（从 GitHub API）
  - 当前版本显示
  - 版本比较
- **下载更新**
  - 重试机制（最多3次，间隔2秒）
  - gzip 文件完整性验证
  - 备份旧版本
  - 失败自动恢复
  - 进度日志输出
- **服务管理**
  - 更新后自动重启服务
  - 安全的内核替换流程

#### 节点管理 🆕
- **手动添加节点**
  - 支持 7 种协议：
    - Shadowsocks (支持所有主流加密方式)
    - VMess (完整配置选项)
    - VLESS
    - Trojan
    - Hysteria
    - Hysteria2
    - TUIC
- **详细配置选项**
  - 传输协议：TCP/WebSocket/HTTP2/gRPC
  - TLS 配置：SNI、证书验证
  - UDP 支持
  - WebSocket/HTTP2 路径和Host配置
- **节点测速**
  - 单个节点测速（TCP 连接延迟）
  - 批量测速所有节点
  - 延迟彩色显示：
    - <150ms：绿色🟢
    - 150-400ms：黄色🟡
    - >400ms：红色🔴
    - 超时：红色⚠️
  - 测速结果持久化

#### 定时任务管理 🆕
- **订阅自动更新**
  - Cron 时间配置
  - 支持多种更新频率
- **内核自动更新**
  - 每周/每月自动检查更新
- **GeoIP/GeoSite 自动更新**
  - 定期更新规则库
- **服务定时重启**
  - 定期重启服务清理连接
- **Cron 管理界面**
  - 可视化配置
  - 当前任务显示
  - 一键应用/清除

#### GeoIP/GeoSite 更新 🆕
- 从 MetaCubeX/meta-rules-dat 更新
- 重试机制
- 自动重载配置

### 🎨 UI/UX 改进

- **订阅列表**
  - 表格布局优化
  - 列宽度调整
  - 多选框样式改进
- **节点列表**
  - 表格视图
  - 延迟实时显示
  - 颜色编码
- **日志系统**
  - 完全符合 OpenClash 风格
  - `Tip:`/`Error:` 前缀规范
  - `##FINISH##` 完成标记
- **整体风格**
  - 保持现代化深色主题
  - 流畅动画
  - 响应式设计

### 🔧 技术改进

- **日志系统重构**
  - 参考 OpenClash 的 `log.sh` 实现
  - `LOG_OUT()` 双写（实时 + 历史）
  - `SLOG_CLEAN()` 完成标记
  - 前缀由调用者提供
- **锁机制**
  - 所有关键脚本添加文件锁
  - 防止并发执行冲突
- **错误处理**
  - 完善的错误捕获
  - 失败自动回滚
  - 详细的错误日志
- **重试机制**
  - 下载操作支持重试
  - 可配置重试次数和间隔

### 📚 文档更新

- **README**
  - 完整的功能列表
  - 详细的安装指南
  - 快速开始教程
  - 与 OpenClash 对比表
  - 适用场景说明
- **使用指南**
  - 已有详细的平台配置教程
  - Windows/macOS/iOS/Android
  - 浏览器扩展
  - 命令行工具
  - Docker 配置

### 🐛 Bug 修复

- 修复订阅更新脚本的文件持久化问题

- 修复 `overview.htm` 的 Lua 语法错误
- 修复 GitHub Actions CI 的网络错误（添加重试）

### 🔄 重构

- **订阅更新脚本** - 完全按照 OpenClash 风格重写
- **配置生成器** - 支持从订阅合并节点和生成代理组
