# SocksClash v1.3.0 规划文档

## 🎯 版本目标

v1.3.0 将是一个**功能增强版本**，重点提升用户体验、增加高级功能、优化性能。

**发布时间**: 2025 Q1（预计 2025年1-3月）

---

## ✨ 规划功能列表

### 1. 订阅管理增强 Plus 📡

#### 1.1 订阅分组
- **功能**: 支持将订阅分组管理
- **场景**: 用户有多个订阅商时，可以分类管理（工作/娱乐/备用）
- **实现**:
  - 添加订阅分组功能
  - 按分组显示节点
  - 支持分组启用/禁用

#### 1.2 订阅转换
- **功能**: 内置订阅转换功能
- **场景**: 某些订阅格式不兼容Clash时，自动转换
- **实现**:
  - 支持 V2Ray/Quantumult 等格式
  - 自动识别并转换
  - 使用本地转换，无需第三方API

#### 1.3 订阅测速排序
- **功能**: 订阅更新后自动测速并排序
- **场景**: 自动选择最快的节点
- **实现**:
  - 更新订阅后自动批量测速
  - 按延迟排序节点
  - 可选保留前N个最快节点

#### 1.4 订阅去重智能化
- **功能**: 更智能的节点去重
- **场景**: 多个订阅有重复节点时自动合并
- **实现**:
  - 按服务器地址+端口去重
  - 保留最优质的节点（根据延迟）
  - 支持手动合并规则

---

### 2. 节点管理增强 🚀

#### 2.1 节点收藏/标签
- **功能**: 为节点添加收藏和自定义标签
- **场景**: 快速找到常用节点
- **实现**:
  - 收藏夹功能
  - 自定义标签（地区/用途/运营商）
  - 按标签筛选

#### 2.2 节点导入/导出
- **功能**: 批量导入/导出节点
- **场景**: 备份节点、在多台设备间同步
- **实现**:
  - 导出为JSON/YAML格式
  - 支持从其他Clash配置导入
  - 批量编辑节点信息

#### 2.3 节点健康检查
- **功能**: 定期自动检查节点健康状态
- **场景**: 自动禁用失效节点
- **实现**:
  - 定时健康检查（每小时/每天）
  - 连续失败N次自动禁用
  - 健康状态可视化

#### 2.4 自定义测速URL
- **功能**: 支持自定义测速目标地址
- **场景**: 测试不同地区/服务的延迟
- **实现**:
  - 多个测速URL配置
  - 按地区/服务分类测速
  - 延迟统计和趋势

---

### 3. Dashboard 增强 🎛️

#### 3.1 连接管理增强
- **功能**: 更详细的连接信息和控制
- **实现**:
  - 显示每个连接的详细信息（进程、类型、流量）
  - 支持关闭单个连接
  - 按规则/节点分组显示连接
  - 连接历史记录

#### 3.2 流量统计增强
- **功能**: 更丰富的流量统计
- **实现**:
  - 每小时/每天/每月流量统计
  - 按节点统计流量消耗
  - 流量趋势图（Chart.js）
  - 流量预警（接近限制时提醒）

#### 3.3 节点切换优化
- **功能**: 更快捷的节点切换
- **实现**:
  - 快捷键切换节点（Ctrl+Shift+N）
  - 最近使用节点列表
  - 节点搜索功能
  - 拖拽排序优化

#### 3.4 实时日志查看
- **功能**: Dashboard 中查看实时日志
- **实现**:
  - 日志级别过滤
  - 日志搜索
  - 日志导出
  - WebSocket 实时推送

### 4. 规则管理增强 📋

#### 4.1 规则集（Rule Providers）🆕
- **功能**: 支持Clash的规则集功能
- **场景**: 大量规则时，使用规则集提升性能
- **实现**:
  - 规则集订阅和更新
  - 常用规则集预设（广告屏蔽/BT直连等）
  - 规则集编辑器

#### 4.2 自定义规则模板
- **功能**: 预设规则模板，一键应用
- **实现**:
  - 常用场景模板（全局代理/国内直连/智能分流）
  - 支持导入/导出规则模板
  - 规则模板市场（社区分享）

#### 4.3 规则优先级调整
- **功能**: 可视化调整规则优先级
- **实现**:
  - 拖拽调整规则顺序
  - 规则分组管理
  - 规则冲突检测

#### 4.4 规则测试工具
- **功能**: 测试某个域名/IP会匹配哪条规则
- **实现**:
  - 规则匹配测试
  - 显示匹配路径
  - 规则性能分析

- **实现**:

#### 5.3 智能代理组
- **功能**: 根据规则自动生成代理组
- **实现**:
  - 按地区自动分组（香港组/台湾组/US组）

## 📊 技术债务

需要在 v1.3.0 中解决的技术问题：

1. **配置生成器重构** - 使用更强大的 YAML 解析器（如 `yq`）
2. **测速优化** - 使用 Clash API 而不是 TCP 连接测试
3. **日志系统** - 统一日志格式，添加日志轮转
4. **错误处理** - 完善所有脚本的错误处理
5. **代码规范** - 统一 Shell/Lua 代码风格

3. **用户体验**: 保持简单易用的核心理念
