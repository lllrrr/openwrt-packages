# SocksClash v1.2.0 升级计划

## 项目定位
**专注代理，极致简化** - 复刻 OpenClash 的优秀功能，但专注于 SOCKS5/HTTP/Mixed 代理场景

## 核心理念
1. **仅代理模式** - 不做透明代理、不劫持 DNS、不修改路由表
2. **功能完整** - 保留订阅、规则、节点管理等核心功能
3. **极致简化** - 移除复杂的网络配置，降低使用门槛
4. **现代界面** - 保持现有的现代化 UI 风格

## 阶段二：数据结构设计

### UCI 配置结构（OpenClash 风格）

```
config openclash 'config'
    option enable '1'
    option cn_port '9090'
    option socks_port '7891'
    option http_port '7890'
    option mixed_port '7893'
    option mode 'rule'
    option log_level 'info'
    option allow_lan '1'
    option bind_address '*'
    option ipv6 '0'
    option dashboard_password ''
    option config_path '/etc/socks-clash/config/config.yaml'

config config_subscribe
    option enabled '1'
    option name 'Subscription1'
    option address 'https://example.com/sub'
    option sub_ua 'ClashMeta'
    option keyword_include ''
    option keyword_exclude ''
    option auto_update '1'
    option auto_update_time '0 6 * * *'

config servers
    option type 'ss'
    option name 'MyProxy'
    option server '1.2.3.4'
    option port '443'
    option cipher 'aes-256-gcm'
    option password '123456'
    option enabled '1'

config proxy_group
    option name 'PROXY'
    option type 'select'
    list proxies 'Auto'
    list proxies 'DIRECT'

config rule
    option type 'DOMAIN-SUFFIX'
    option payload 'google.com'
    option policy 'PROXY'
```

### 目录结构（OpenClash 风格）

```
/etc/socks-clash/
├── config/                  # 配置文件目录
│   ├── config.yaml         # 当前配置
│   ├── subscription1.yaml  # 订阅配置
│   └── backup/             # 配置备份
├── core/                   # 内核目录
│   └── clash              # Clash Meta 内核
├── rule/                   # 规则文件
│   ├── geoip.dat
│   └── geosite.dat
└── dashboard/              # Dashboard 文件（可选）

/tmp/
├── socks-clash.log         # 历史日志
├── socks-clash_start.log   # 实时日志
└── lock/                   # 锁文件目录
```

## 技术债务和注意事项

### 需要注意的点
1. **配置兼容性** - 确保 OpenClash 配置文件可以直接导入
2. **内核兼容性** - 只支持 Clash Meta，不支持 Premium
3. **性能优化** - 大量节点时的性能问题
4. **安全性** - Dashboard 密码保护

### 已知限制
1. **不支持透明代理** - 这是设计决策
2. **不支持 FakeIP** - 仅代理模式不需要
3. **不支持 TUN 模式** - 仅代理模式不需要
